# Personas

## Customer

### Description

An external user who wants to access company services through the portal. The
only persona the current scope serves.

### Goals

- Register quickly
- Log in securely
- Manage personal information
- Access services

### Frustrations

- Complicated registration
- Weak security
- Losing access with no obvious way back in

---

## Administrator

### Description

An internal employee responsible for platform management. **Future persona** —
no administrator role, endpoint, or permission is defined in the current scope,
and roles beyond `CUSTOMER` are an Open Decision in `AGENTS.md`. Do not design
for this persona until that decision is resolved.

### Goals

- Manage users
- Investigate issues
- Maintain security

### Frustrations

Not yet gathered. This persona is out of scope, so no Story may cite a frustration
here as a requirement.
